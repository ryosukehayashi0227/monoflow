# MonoFlow

**MonoFlow** is a minimalist yet powerful, browser-based personal Kanban tool designed for high-performance productivity. No servers, no sign-ups, and complete privacy—your data never leaves your browser.

## ✨ Key Features

- **Zero Setup:** No installation required. Open `index.html` and start immediately.
- **Privacy First:** 100% of data is stored in your browser's `Local Storage`.
- **Advanced Task Management:**
  - **Hierarchy:** Subtasks with progress bars and visual indentation.
  - **Virtual Tickets:** Maintain context across lanes with ghost cards and a smooth "Jump & Flash" navigation feature.
  - **Priorities & Labels:** Organize with color-coded priorities and custom multi-select labels.
- **Productivity Analytics:**
  - **Metrics:** Track status distribution and average lead times.
  - **Burndown Chart:** Visualize work remaining against ideal progress.
- **Smart Interface:**
  - **Dark Mode:** Sleek dark interface for late-night focus.
  - **Quick Search:** Full-text search across titles and notes.
  - **Multilingual:** Full support for Japanese and English.
  - **Archive:** Keep your board clean by moving completed projects to the archive.
- **Data Portability:** Robust Export/Import (JSON) for backups and migration.

## 🚀 How to Use

1.  Download or clone the repository.
2.  Open `index.html` in any modern web browser (Chrome, Safari, Firefox, Edge).
3.  Check out the built-in **User Guide** (accessible via the `?` icon) for deep dives into specific features.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Vanilla JavaScript (ES6+), CSS3
- **Styling:** Tailwind CSS (via Play CDN)
- **Interactive:** SortableJS (Drag & Drop), Chart.js (Analytics)
- **Icons:** Lucide Icons
- **Data:** Web Storage API (Local Storage)
