# Monoflow

**Monoflow** is a simple, beautiful, and private Kanban board that lives entirely in your browser. No servers, no sign-ups, no data leaks.

![Monoflow Screenshot](https://placehold.co/800x400/e2e8f0/1e293b?text=Monoflow+Preview)

## ✨ Features

- **Zero Setup:** Just open the file. No installation required.
- **Private:** All data is stored in your browser's `Local Storage`.
- **Drag & Drop:** Smooth, intuitive Kanban experience powered by SortableJS.
- **Detailed Tasks:** Add descriptions and due dates to your tasks.
- **Modern Design:** Built with Tailwind CSS and Inter font for a clean look.

## 🚀 How to Use

1.  Download the `index.html` file.
2.  Open it in any modern web browser (Chrome, Firefox, Safari, Edge).
3.  Start organizing your tasks!

## 🛠️ Tech Stack

- **HTML5 / JavaScript (ES6+)**
- **Tailwind CSS** (via CDN)
- **SortableJS** (for Drag & Drop)
- **Lucide Icons**
