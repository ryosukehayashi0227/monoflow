# MonoFlow

**MonoFlow** is a simple, beautiful, and private Kanban board that lives entirely in your browser. No servers, no sign-ups, no data leaks.

## ✨ Features

- **Zero Setup:** Just open the file. No installation required.
- **Private:** All data is stored in your browser's `Local Storage`.
- **User Guide:** Built-in operations manual.
- **Metrics:** Visual analytics for your tasks and progress.
- **Drag & Drop:** Smooth, intuitive Kanban experience.
- **Detailed Tasks:** Add descriptions, due dates, priorities, and custom labels.
- **Modern Design:** Built with Tailwind CSS and Inter font.

## 🚀 How to Use

1.  Download the project.
2.  Open `index.html` in any modern web browser.
3.  Start organizing your tasks!
